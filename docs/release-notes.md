This preview replaces input sampling with symbolic probability-law propagation. Numerical CDF evaluation and optional final-law draws occur only in the visualization layer. Shared wires retain source identity, including through feedback.

Includes:

- Named ports, drag-to-connect, endpoint reconnection, saved wire routing, and configurable/inferred custom input signatures, including twelve-input functions.
- Python/SymPy and Julia/Symbolics script exports containing the equation system, source identities, feedback expansion, and every visualization tap.
- Standalone Windows and Linux launchers, Ubuntu DEB, EL9 RPM, a Docker image archive, and SHA-256 checksums.
- Offline runtime assets and fonts; no Node installation is needed for native packages.

Open `START-HERE.txt` inside a portable archive, or see the repository README for installation commands and export dependencies.

This is an unsigned preview. General laws remain symbolic when a numerical plot cannot be evaluated within the documented rendering limits. Numerical special functions, finite plotting windows, quadrature, moments, and final-CDF interpolation are visualization approximations and are labeled. SysML output remains an unvalidated textual draft. Models and their Git history remain in your browser profile; export them before moving to a different browser or origin.
